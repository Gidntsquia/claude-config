Question Which GPU change, if any, should ship, and what is the next build? Candidates: every GPU change that has an interleaved A/B against default in the data — compact state (POGO_GPU_STUDY=stack), occupancy (occni), tail speculation (tail), tail with certain feed (tail,certain) and tail v2. Decide by warm seconds per generation in the interleaved A/B (10-gen halving-3 standard command): a change ships when its gain beats both arms' spreads with at least 2 runs per arm, and its results are identical to default (verify 100%, same-seed checkpoints identical). Also report, for the change that ships, its tail share against default and the full standard run's total wall against default.

Tail speculation and the certain feed in the 11:53 ET A/B supports: row: tail

Tail speculation (POGO_GPU_STUDY=tail) lets idle GPU lanes run next-round battles while a launch's last battles finish.

The certain feed (tail,certain) adds the battles of teams already sure to survive the cut.

That is one run each, because r9-ab-default-2 stopped at gen 5 with no exit code.

At n = 1 the gain is unproven, so the later build needs its own A/B.
