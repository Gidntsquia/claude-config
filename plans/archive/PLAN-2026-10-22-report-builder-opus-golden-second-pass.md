## What to build
A new `agents/report-writer.md`, written from scratch, that turns `<data dir> — <question>` into a storyteller essay of the golden r5 shape: `report.md` whose every figure is a `{key}` into `numbers.json`, rendered by a build script to `report.html` and 390 px phone cards, gated by `check.py --prose` (ai_tells included) and reviewed by the `report-checker` subagent. The agent carries the persona, writes the opening last from ten candidates, self-reviews against `docs/ai-tells.md`, and picks the length from the question. The agent runs on Opus at medium effort. A new eval harness, `~/files/agent-eval-experiment/report-writer/report_eval.py`, runs the agent on cases with no human and scores each run by mechanical checks only (check.py --prose, structure, expected figures and traps from a frozen accepted report) plus FE tokens and wall time; the GPU study is the first case, with expected values frozen from golden r5 B. Four fixtures are added from the user's past studies (worker evals, planner evals, token experiment, MCP token cost), each with the verbatim ask pulled from the session logs; `--promote` turns an accepted fixture into a case. This round the builder runs on GPU, worker, token and MCP, each twice (checker on and off), plus planted errors; the checker's findings, hit rate and cost become a fifth data directory from which the builder writes the report on the checker. The evaluator shows all cards on the phone, one labeled set per report.
